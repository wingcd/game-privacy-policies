## 文件说明

- `index.html` — 隐私政策页面（中英双语，单文件自包含），手机/桌面自适应，默认按浏览器语言显示，右上角可手动切换

## 内容依据（写了什么、为什么）

按项目实际情况写的，没有夸大数据收集范围：

- **平台账号标识**：游戏通过宿主平台启动，用平台 UID 识别账号（不收集手机号/身份证）
- **设备信息**：机型、系统、分辨率、网络状态（做适配）
- **游戏数据**：进度存本地；打点为匿名玩法统计（进入游戏、关卡进度、游戏结果、广告观看结果等，见 `docs/打点.xlsx`）
- **日志**：异常排查
- **第三方**：激励视频广告 SDK、CDN 资源下载、平台支付——均按"以其自身政策为准"的通用表述处理，未绑定具体平台

如果以后游戏新增收集项（如接入收集设备标识的统计 SDK），需要同步更新页面并改日期。
