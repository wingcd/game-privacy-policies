# 《消个毛线》隐私政策

给 SUD 平台提交用的隐私政策页面（中英双语，单文件，无外部依赖）。

## 文件说明

- `index.html` — 隐私政策页面，自包含（样式、脚本都内联），手机/桌面自适应，默认按浏览器语言显示中文或英文，右上角可手动切换。

## 在线地址

部署在本仓库的 GitHub Pages 上：

- https://wingcd.github.io/game-privacy-policies/消个毛线/

（平台后台需要填 URL 时，直接用上面的地址；如遇不支持中文路径的平台，可把文件夹改成英文名再推送。）

## 需要注意 / 后续要改的地方

| 位置 | 说明 |
| --- | --- |
| `ENGLISH_NAME` | 英文版正文中游戏英文名的占位，英文名定下来后全局搜索 `ENGLISH_NAME` 替换 |

| 邮箱 | 目前用 `wingcd@foxmail.com`，如换主体邮箱需全局替换 |
| 公司主体 | 目前写的是「《消个毛线》开发团队」，如以后以公司名义发行，改 header 副标题和英文版对应位置 |

## 内容依据（写了什么、为什么）

按项目实际情况写的，没有夸大数据收集范围：

- **平台账号标识**：游戏通过宿主平台启动，用平台 UID 识别账号（不收集手机号/身份证）
- **设备信息**：机型、系统、分辨率、网络状态（做适配）
- **游戏数据**：进度存本地；打点为匿名玩法统计（进入游戏、关卡进度、游戏结果、广告观看结果等，见 `docs/打点.xlsx`）
- **日志**：异常排查
- **第三方**：激励视频广告 SDK、CDN 资源下载、平台支付——均按"以其自身政策为准"的通用表述处理，未绑定具体平台

如果以后游戏新增收集项（如接入收集设备标识的统计 SDK），需要同步更新页面并改日期。
