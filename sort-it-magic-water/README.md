## 与 yarn-match 政策的差异

本项目与《消个毛线》(Yarn Match) 同框架（thread-jam 换皮），数据收集一致，另有一处已按实际代码补进政策：

- **用户信息（昵称、头像）**：本项目有服务端排行榜（`ServerController.ts` / `GameUserInfo.ts` 会将平台昵称、头像同步到游戏服务器用于排行展示），政策第一节第 2 条即对应此项。yarn-match 的政策也已同步补上此条（其好友排行同样涉及）。
